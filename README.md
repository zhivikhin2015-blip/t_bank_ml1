# Автоматизация признаков для рекомендаций

Учебное исследование на FAR-Trans: ручной градиентный бустинг и автоматическая генерация и отбор признаков.

- **[REPORT.md](REPORT.md)** — полная версия отчёта: постановка задачи, формулы и реализации кодом, реальные примеры, эксперименты, выводы, ограничения и воспроизведение.
- **[report_short.html](report_short.html)** — короткая удобная версия: основные результаты и выводы, компактные таблицы и кнопки навигации. Откройте локальный HTML-файл в браузере; интернет для просмотра не нужен.

Для быстрого знакомства начните с `report_short.html`. Для подробной оценки и повторения экспериментов используйте `REPORT.md`.

Код — `src/`, тесты — `tests/`, ноутбуки — `notebooks/`, данные — `data/`, фиксированные результаты — `results/`.

# Автоматизация признаков для рекомендаций финансовых активов

Исследование на FAR-Trans: ручной градиентный бустинг с 44 признаками, генерация 102 кандидатов, автоматический отбор и экспериментальное сравнение.

**[Открыть единый отчёт для оценки → REPORT.md](REPORT.md)**

Отчёт содержит постановку задачи, описание данных, временной протокол, формулы и полный каталог признаков, реальные примеры расчёта и top-5, настройку моделей, результаты, интервалы неопределённости, ограничения, выводы и команды воспроизведения. Для понимания работы не требуется читать остальные файлы.

На июле–октябре 2022 ручная модель получила **65,53% Recall@5**, автоматический отбор — **64,32%**, объединённая модель — **64,39%**. Преимущество автоматизации по основной метрике не подтверждено. Период ранее оценивался, поэтому выводы имеют исследовательский статус.

## Быстрый запуск

Требуется Python 3.15. Полный протокол установки и запуска приведён в [разделе 12 отчёта](REPORT.md#12-воспроизведение-и-источники).

```bash
python3.15 -m venv .venv
source .venv/bin/activate
python -m pip install -r environment/requirements-lock.txt
python -m pip install -e . --no-deps
python -m research.feature_automation.prepare_data --out data/processed
python -m unittest discover -s tests -v
```

Подготовленные таблицы, новые экспериментальные запуски и временные файлы исключены из Git. Имя модуля `research.feature_automation` сохранено для совместимости с зафиксированными моделями.
